## About

Cybersecurity MSc candidate at the University of Genova specialising in **Active Directory security**, **threat detection**, and **PKI infrastructure**.

At **Teoresi Group**, I built a full enterprise AD lab from the ground up — simulating Kerberoasting, Pass-the-Hash, ACL abuse, and credential dumping, then wrote Python detection logic and playbooks mapped to MITRE ATT&CK. At **Ericsson**, I designed and deployed a Certificate Authority for microservice authentication in a production telecommunications environment.

Before cybersecurity, I spent four years administering Active Directory in a government institution. I understand enterprise Windows environments from an operational perspective — not just from lab work.

My Java and Spring Boot background is a secondary asset: it helps me trace application-layer attack surfaces and read code during log investigations.

> **Seeking:** Junior SOC Analyst · Junior Cybersecurity Engineer · Security Analyst · Blue Team roles in Italy.
